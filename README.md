# Disponibilidad de Notebooks
Propuesta de mejora para el aula virtual: una extensión para reservar y consultar la disponibilidad de las notebooks de la escuela.

## Descripción

Los estudiantes y profes de la escuela tienen muchos problemas a la hora de pedir notebooks, a veces no hay, las disponibles están con algunos defectos, o no tienen los programas necesarios para las materias. Este proyecto propone una **extensión del aula virtual** que mejore la disponibilidad de las notebooks, facilite a los profesores su reserva y le dé a los directivos una visión más clara del estado de los equipos.

## Problemas detectados

- Poca disponibilidad de notebooks.
- Algunas notebooks tienen teclas faltantes.
- Los horarios de reserva se superponen.
- Faltan programas necesarios para algunas materias.

## Propuesta

- **Reserva simple para profesores:** elegir notebooks de forma fácil y visual.
- **Vista clara para directivos:** panorama ordenado de la disponibilidad y el estado de los equipos.
- **Reporte de problemas:** un apartado para notificar fallas de una notebook, como teclas faltantes o una batería defectuosa.
- **Filtro de búsqueda por programas:** permite encontrar las computadoras que tienen el software necesario para cada materia.

## Interfaz de Usuario 

El proyecto busca una interfaz sencilla y fácil de entender porque está dirigida a todos los profes y alumnos de la escuela que necesiten computadoras (no solo de informática).

Lo primero que uno encontrará al ingresar a la página es un login, y según las credenciales, tendrá el rol "estudiante", "profesor" o "admin". Al ingresar nos encontraremos un Dashboard según nuestro rol.

### Información al pasar el cursor (hover)

Al pasar el puntero sobre una notebook se muestra un texto con lo que el profesor debe saber antes de elegirla (teclas faltantes u otros problemas). Estos problemas son **reportados por alumnos y profesores** y luego **aprobados** antes de mostrarse.
